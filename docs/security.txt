AutoMind Inc. — Security & Compliance

Document Classification: Public
Last Updated: February 2025

1. Data Encryption
All data is encrypted at rest using AES-256 encryption. Data in transit is protected using TLS 1.3. API keys are hashed using bcrypt with a cost factor of 12 before storage.

2. Data Residency
By default, all data is stored in US-East (Virginia) data centers. Enterprise customers can choose from the following regions:
- US-East (Virginia)
- US-West (Oregon)
- EU-West (Frankfurt)
- Asia-Pacific (Tokyo)
- Asia-Pacific (Sydney)

3. SOC 2 Type II Compliance
AutoMind has achieved SOC 2 Type II compliance as of January 2025. Our annual audit is conducted by Deloitte. The audit report is available to Enterprise customers upon request via their account manager.

4. GDPR Compliance
AutoMind is fully GDPR compliant. Users can:
- Request data export (within 30 days)
- Request data deletion (within 72 hours)
- Opt out of data processing for model improvement
- Access their data processing agreement (DPA) from Account Settings

5. Access Control
AutoMind uses role-based access control (RBAC) with four roles:
- Owner: Full access, billing, team management
- Admin: Full access except billing
- Developer: API access, project management
- Viewer: Read-only access to dashboards and logs

All accounts require multi-factor authentication (MFA). We support TOTP-based authenticators (Google Authenticator, Authy) and hardware security keys (YubiKey).

6. Incident Response
AutoMind maintains a 24/7 security operations center (SOC). Our incident response SLA:
- Critical (data breach): Response within 1 hour, notification within 24 hours
- High (service degradation): Response within 4 hours
- Medium (potential vulnerability): Response within 24 hours
- Low (informational): Response within 72 hours

Security incidents are reported to affected customers via email and posted on our status page at status.automind.ai.

7. Penetration Testing
AutoMind conducts quarterly penetration tests performed by independent security firms. Results are shared with Enterprise customers upon request.

8. Data Retention
- Free tier: 7 days
- Pro tier: 90 days
- Enterprise: Custom (configurable up to 7 years)
After the retention period, data is permanently deleted within 30 days. Deletion is irreversible.

9. Bug Bounty Program
AutoMind operates a bug bounty program. Responsible disclosure of security vulnerabilities is rewarded:
- Critical: $5,000 - $10,000
- High: $1,000 - $5,000
- Medium: $250 - $1,000
- Low: $50 - $250
Report vulnerabilities to security@automind.ai.
