AutoMind Inc. — Pricing & Plans

Last Updated: March 15, 2025

1. Free Tier
- Price: $0/month
- Features: 100 API calls/day, 1 project, community support, basic models only
- Rate limit: 10 requests per minute
- No SLA guarantee
- Data retention: 7 days

2. Pro Plan
- Price: $49/month (or $470/year — save 20%)
- Features: 10,000 API calls/day, 10 projects, email support (24hr response), all models including GPT-4o and Claude
- Rate limit: 100 requests per minute
- 99.5% uptime SLA
- Data retention: 90 days
- Custom system prompts and fine-tuning access

3. Enterprise Plan
- Price: Custom pricing (contact sales@automind.ai)
- Features: Unlimited API calls, unlimited projects, dedicated account manager, phone support (4hr response)
- Rate limit: Custom (typically 1000+ requests per minute)
- 99.99% uptime SLA
- Data retention: Custom (up to 7 years for compliance)
- On-premise deployment option
- SOC 2 Type II compliance
- Custom model training and hosting
- Priority access to new features

4. Add-ons (available for Pro and Enterprise)
- Extra API calls: $10 per 5,000 additional calls
- Priority support: $29/month (1hr response time)
- Dedicated GPU: $199/month per GPU instance
- Custom domain: $15/month

5. Billing
All plans are billed monthly or annually. Annual plans receive a 20% discount. Invoices are sent on the 1st of each month. Payment methods accepted: Visa, Mastercard, American Express, wire transfer (Enterprise only).

6. Fair Use Policy
AutoMind reserves the right to throttle or suspend accounts that exceed 10x their plan's API limit. Repeated violations may result in account termination.
